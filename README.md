# Naniro

![naniro](https://github.com/user-attachments/assets/e368f042-35b8-4faf-9b48-ed994863926f)
Naniro is a simple web-based game designed to help users identify colors in images or through interactive color selection. The game provides an intuitive interface for users to select colors and view corresponding color codes and names.

## Features
- Allows users to interact with color selections and view details such as color names and codes.
- A web interface built using HTML, CSS, and JavaScript.
- Help button feature for user assistance.
- Stats tab that shows the winrate for the user.

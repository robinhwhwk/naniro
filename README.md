# Naniro

![naniro](https://github.com/user-attachments/assets/e368f042-35b8-4faf-9b48-ed994863926f)
Naniro is a simple web-based application designed to help users identify colors in images or through interactive color selection. The application provides an intuitive interface for users to select colors and view corresponding color codes and names.

## Features
- Allows users to interact with color selections and view details such as color names and codes.
- A web interface built using HTML, CSS, and JavaScript.
- Help button feature for user assistance.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/robinhwhwk/naniro.git
    ```

2. Open the `index.html` file in your browser to start using the application.

## Requirements
- A modern web browser.

## Usage
1. Open the `index.html` file.
2. Use the interactive tools to explore and identify colors.
3. The application displays the name and code of the selected color for reference.
